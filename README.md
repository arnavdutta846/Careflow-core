# Healthcare Process Performance Dashboard

An interactive Power BI dashboard designed to analyze and monitor healthcare process performance.

## Key Insights

- Analyze total patients, cases, and healthcare events
- Identify patient distribution by gender, age group, race, and country
- Analyze patient activity and process transitions
- Monitor average and minimum waiting times
- Identify patients with average waiting time ≤ 20 minutes
- Identify healthcare activities with average waiting time > 20 minutes
- Analyze daily and monthly patient trends
- View detailed patient-level information
- Compare waiting time across different healthcare activities and transitions

## Dashboard Pages

- Executive Overview
- Monthly View
- Patient Process
- Patient Data

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
